# Archive

Historical documents. Kept as a record of how the software got here, not as a description of what it
is now.

**Every path, file name, module name and command in this directory is expected to be broken**, and
they are left that way deliberately. These files describe a repository layout that no longer exists:
two separate crates, `ev-peak-contrib` and `green-button`, merged into this one. Repairing a path
here would turn a historical record into a document describing something that never existed, which
is worse than a link that plainly does not resolve.

If you are looking for how the software works today, start from the root `README.md`.
